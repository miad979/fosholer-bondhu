# Quick Start Guide - Fosholer Bondhu Presentation

## 🚀 Getting Started (2 Minutes)

### Step 1: Install Dependencies
```bash
pip install python-pptx
```

### Step 2: Generate Presentation
```bash
python generate_presentation.py
```

That's it! You now have `Fosholer_Bondhu_Presentation.pptx` ready.

## 💡 Presentation Tips

### Timing:
- Aim for 15-20 minutes total
- ~1 minute per slide average
- Allow 5 minutes for Q&A

### Best Practices:
- Practice 3-4 times before presenting
- Memorize key points, don't read slides
- Make eye contact with audience
- Explain technical terms clearly
- Show enthusiasm for your project

### Common Questions to Prepare:
1. Why did you choose MobileNetV2?
2. How did you handle class imbalance?
3. What are the main challenges in deployment?
4. How accurate is it compared to expert diagnosis?
5. Can this scale to other crops?
6. What's the total development time?

## 🔧 Troubleshooting

**Error: No module named 'pptx'**
```bash
pip install python-pptx
```

**Want to regenerate?**
```bash
rm Fosholer_Bondhu_Presentation.pptx
python generate_presentation.py
```

**Need to modify colors or fonts?**
Edit the constants in `generate_presentation.py`:
```python
PRIMARY_COLOR = RGBColor(0, 102, 204)    # Blue
SECONDARY_COLOR = RGBColor(76, 175, 80)  # Green
ACCENT_COLOR = RGBColor(255, 152, 0)     # Orange
```
